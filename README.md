Weather Data Analyzer

This project is a Weather Data Analyzer built using Python. It loads historical weather data, analyzes trends in temperature, humidity, and rainfall, and uses **Linear Regression** to forecast future temperature trends. The visual outputs help meteorologists, researchers, or weather enthusiasts understand climate patterns over time.

 Features

  Clean and preprocess historical weather data
  Perform statistical and correlation analysis
  Visualize trends using:
  Line charts (temperature trends)
  Bar charts (rainfall by year)
  Scatter plots (temperature vs humidity)
  Heatmaps (feature correlations)
  Forecast future temperature trends using Linear Regression
  Model evaluation using MSE and RMSE



Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


 Files Included

File Name                                              
`project.py`            Main Python script with analysis & modeling 
`weather_data.csv`      Sample dataset of weather records (2010–2024) 
.png` files           Graphs saved as images automatically

 How to Run

1. Make sure you have Python installed.
2. Install required libraries (if not already installed):
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn
   ```
3. Run the script:
   ```bash
   python project.py
   ```
4. Check the generated `.png` files for visual outputs.
